# MapForge
Reusable C++ geospatial library and command-line application capable of importing OpenStreetMap data, constructing road networks, calculating routes, and performing spatial searches.
A C++20 geospatial processing engine focused on geographic data processing, road network modeling, and route optimization.

## Project Goals

- Process OpenStreetMap geographic data.
- Construct road network graphs.
- Calculate geographic distances.
- Implement shortest-path algorithms.
- Support spatial searches.
- Evaluate algorithm performance.

## Technology Stack

- C++20
- GCC
- CMake
- Ninja
- GoogleTest
- Boost.Geometry

## Build Instructions

```bash
cmake -S . -B build -G Ninja
cmake --build build
```
